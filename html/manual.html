Contestant Machine Manual

Local User Account

Each contestant machine has a single local (Ubuntu 24.04) user account: ioi, with the default password ioi.

Do not change the password of the ioi account to avoid confusion.

Contestant Account

Upon your first login, and every subsequent login until the process is complete, you will be prompted to run the IOI Setup.

Use your contestant credentials (currently both username and password are ioi) and wait for a success confirmation.

Applications

The sidebar on the left is called the Launcher.

The top icon launches the Firefox web browser, which opens to a homepage containing links to CMS and local documentation.

The Show Applications icon at the bottom of the Launcher displays all installed applications. Use the search bar to find apps by name, e.g., typing terminal will locate gnome-terminal.

Advanced Features

Home Directory Backup (not yet available)

The system supports replication of the home directory using rsync to the IOI 2025 backup server. This feature is disabled by default.

  • Use ioibackup to trigger a manual sync.
  • Enable automatic backup every 5 minutes using ioiconf setautobackup on.
  • Disable it with ioiconf setautobackup off.

Backups are only available during contest and practice sessions.

Note: This is a replication (not archival) system. It uses rsync --delete, which mirrors local deletions on the remote server. Only non-hidden files under 100KB are synced.

To recover files, use ioibackup -r. Files will be restored in /tmp/restore.

Automatic Screen Lock

The screen locks after 15 minutes of inactivity, with a 30-second warning. To disable this:

  • ioiconf setscreenlock off — disable
  • ioiconf setscreenlock on — re-enable

Timezone

The system clock is set to the America/La_Paz timezone. All official times from the IOI 2025 organizers use this timezone unless stated otherwise.

If you prefer another timezone, use ioiconf settz <timezone>. Example:

ioiconf settz UTC

This takes effect at your next login.

Importing VSCode Extensions

The C/C++ extension is preinstalled. The following additional extensions are available for manual installation:

  • VSCode VIM
  • IntelliJ IDEA Keybindings
  • clangd (as an alternative to the C/C++ extension; known to be occasionally unstable)

To install:

  1. Open VSCode
  2. Click the Extensions icon on the left sidebar
  3. Click the "..." menu in the top-right corner
  4. Select "Install from VSIX..."
  5. Navigate to the extra-vsc-exts bookmark
  6. Select the desired extension
